# Settings Implementation Plan

> Executed inline (native), as the user asked for spec and build in one go. Each task is test-first; the test code lives in the repo files named below.

**Goal:** A Settings window with per-state colors and presets, size and opacity sliders, and follow-the-pointer, all live and persisted.

**Spec:** `docs/superpowers/specs/2026-10-15-settings-design.md`

## Global Constraints

- **Presets:** exact values from the spec. Agents view must equal today's colors bit for bit.
- **Limits:** diameter 40–160 (default 72); opacity 0.3–1 (default 1); panel side = diameter ÷ 0.6.
- **Storage:** a single JSON blob under UserDefaults key `preferences`. Corrupt or missing gives the defaults.
- **Live changes:** every setting applies immediately. The hover list stays fully opaque.
- **Commits:** no AI attribution.

## Review Focus

1. **A smaller display:** the relative spot from a big display must land fully on screen. Covered by `RelativePlacementTests.testClampsOnASmallerDisplay`.
2. **Corrupt or out-of-range preferences:** they must give working defaults, never a crash or a zero-size orb. Covered by `PreferencesTests.testCorruptBlobGivesDefaults` and `testClampsOutOfRangeValues`.
3. **Very dark or very light custom colors:** they must still derive valid colors in the 0–1 range. Covered by `PaletteTests.testDerivationStaysInRange`.
4. **Changing palette mid-animation:** the colors must ease over rather than jump. Covered by `PaletteTests.testAnimatorEasesToANewPalette`.
5. **Resizing near a screen edge:** the orb must stay on screen. This is done by reusing `RelativePlacement.origin` clamping after a resize, and checked by hand.

### Task 1: Palettes in core

**Files:**
- Create: `Sources/ClaudeBubbleCore/OrbPalette.swift`
- Modify: `OrbParams.swift` (target takes a palette, swatch from the palette), `OrbAnimator.swift` (`palette` property)
- Test: `Tests/ClaudeBubbleCoreTests/PaletteTests.swift`

**Produces:**
- `StateColors { c1, c2, c3, halo, swatch: SIMD3<Float> }`
- `OrbPalette { idle, working, needs, error }`, with:
  - `subscript(BubbleState) -> StateColors { get set }`
  - presets `.agentsView`, `.originalDesign`, `.blue`
  - `OrbPalette.presets: [(name: String, palette: OrbPalette)]`
  - `OrbPalette.preset(named:) -> OrbPalette?`
- `PaletteDerivation.colors(from base: SIMD3<Float>) -> StateColors`
- `OrbParams.target(for:palette:)`; `target(for:)` keeps working and uses `.agentsView`
- `OrbAnimator.palette: OrbPalette` (settable)

**Tests (written first, watched fail):**
- Agents view equals the old `OrbParams` colors.
- Original design and Blue match the JS values.
- `swatch` for working is c2 in Agents view.
- Derivation: c1 equals the base, c3 is lighter, the halo is darker, c2's hue moves by −25°, and everything stays within 0–1 for black, white and saturated inputs.
- The palette round-trips through JSON.
- The animator eases to a new palette: one step later the color has moved but not arrived, and two seconds later it has arrived.

### Task 2: Preferences and geometry in core

**Files:**
- Create: `Sources/ClaudeBubbleCore/BubblePreferences.swift`, `Sources/ClaudeBubbleCore/RelativePlacement.swift`
- Test: `Tests/ClaudeBubbleCoreTests/PreferencesTests.swift`, `RelativePlacementTests.swift`

**Produces:**
- `BubblePreferences` (Codable, Equatable): `palette`, `presetName`, `customized`, `diameter`, `opacity`, `followPointer`, `relativeSpot: [Double]?`. Also:
  - `static let defaults`
  - `static func load(from: UserDefaults) -> BubblePreferences`
  - `func save(to: UserDefaults)`
  - `func clamped() -> BubblePreferences`
- `OrbSize.minDiameter = 40`, `maxDiameter = 160`, `panelSide(forDiameter:) -> CGFloat` (clamped ÷ 0.6)
- `RelativePlacement.spot(of frame: CGRect, in visible: CGRect) -> CGPoint` and `RelativePlacement.origin(for spot: CGPoint, side: CGFloat, in visible: CGRect) -> CGPoint` (clamped inside)

**Tests:** defaults; save/load round trip; corrupt blob gives defaults; clamping; unknown preset name falls back to Agents view; panel side and its clamping; spot round trip; clamping on a smaller display; the bottom-center spot.

### Task 3: App wiring and Settings window

**Files:**
- Create: `Sources/ClaudeBubble/SettingsModel.swift` (an ObservableObject over `BubblePreferences` that saves on change), `Sources/ClaudeBubble/SettingsWindow.swift`
- Modify:
  - `AppDelegate.swift`: a Settings… menu item; Combine sinks for palette, diameter, opacity and follow; follow-the-pointer in `updateHover`
  - `BubblePanel.swift`: `setDiameter(_:)` keeping the center, a pips frame that scales, the relative spot saved on drag while following
  - `SessionsModel.swift`: `palette` and `snapshots` become published
  - `SessionViews.swift`: pips and rows read colors and snapshots from the model
  - `OrbSnapshot.swift`: `render(state:size:palette:)`

**Checks:**
- `swift test`, `Tests/hook_test.sh` and `scripts/bundle.sh` all pass with no warnings.
- By hand:
  - the sliders resize and fade the orb live;
  - presets, color wells and Reset;
  - follow the pointer across displays;
  - settings survive a Restart.
