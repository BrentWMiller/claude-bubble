# Usage Implementation Plan

> Executed inline (native); the user asked for spec and build in one go. Each task is test-first.

**Spec:** `docs/superpowers/specs/2026-10-15-usage-design.md`

## Global Constraints

- **Thresholds:**
  - levels at 25 and 10 (percent left);
  - the tint starts at 50% left;
  - low-usage pose: scale 0.88, speed 0.4, glow 0.6.
- **Data sources:** usage comes only from the status line wrapper's `usage.json`. No keychain, no network.
- **The wrapper:** never changes the user's status line output, and never wraps itself.
- **The "Show usage" setting** turns off all four pieces.
- **Commits:** no AI attribution.

## Review Focus

1. **Reset time passes with no new reading** (no Claude session running): left reads 100, the tint and low-usage mode clear, and refresh fires once if a threshold had fired. Covered by `testRefreshFiresWhenResetPassesWithoutNewReading`.
2. **A stale reading at launch** that is already below 10%: no toast, but the tint and low-usage mode apply. Covered by `testFirstReadingIsBaseline`.
3. **Install run twice, or the status line command already wrapped:** no double wrap, and the inner command is kept. Covered by `testInstallIsIdempotent`.
4. **The inner command contains quotes or pipes:** the wrapper runs it through `bash -c` and the output is the same. Covered by the shell test "inner with pipe".
5. **Usage toggled off and on while below a threshold:** no toast burst. Covered by `testResetBaselineSuppressesCrossings`.

### Task 1: Core — UsageReading, UsageTint, UsageAlerts

- **Create:** `Sources/ClaudeBubbleCore/Usage.swift`
- **Test:** `Tests/ClaudeBubbleCoreTests/UsageTests.swift`
- **Produces:**
  - `UsageReading(usedPercent:resetsAt:capturedAt:)` with `.load(from: URL)`, `.decode(Data)`, `left(at:)`, `level(at:)`, `timeLeft(at:)`; `UsageLevel { ok, low, critical }`
  - `UsageReading.defaultURL`
  - `UsageTint.amounts(left:) -> (warm: Float, critical: Float)`
  - `UsageTint.apply(_ params: OrbParams, state:, palette:, warm:, critical:) -> OrbParams`
  - `UsageAlerts` with `update(_ reading: UsageReading?, now: Date) -> [UsageAlert]` and `reset()`
  - `UsageAlert { kind: ToastKind; text: String }`

### Task 2: Toasts — text override and usage kinds; preferences

- **Modify:** `Toasts.swift`, which gains:
  - kinds `usageLow`, `usageCritical`, `usageRefreshed`;
  - `push(_:name:text:now:)`;
  - `ToastPlacement.text`.
- **Modify:** `BubblePreferences.swift`, which gains `usage: Bool`.
- **Test:** the toast and preferences tests.

### Task 3: Animator — usage tint and low-usage pose

- **Modify:** `OrbAnimator.swift`, which gains:
  - `usageLeft: Double?` (nil = off);
  - an eased tint and pose inside `step`.
- **Test:** `UsageAnimatorTests.swift`.

### Task 4: Wrapper script and installer

- **Create:** `hook/claude-bubble-statusline.sh` and `Tests/statusline_test.sh`.
- **Modify:**
  - `HookInstaller.swift`: `wrapStatusLine(settings:wrapper:innerURL:)` and `install(...)` with the wrapper;
  - `scripts/bundle.sh`: copy the script in;
  - `AppDelegate`: refresh the installed wrapper.
- **Test:** `HookInstallerTests` and the shell test.

### Task 5: App wiring

- **Modify:**
  - `SessionsModel`: `usage`, `usageEnabled`;
  - `SessionViews`: the footer;
  - `AppDelegate`: poll every 5s, the animator, toasts, the menu toggle, the simulator source;
  - `SettingsWindow`: the toggle;
  - `SimulatorModel` and `SimulatorWindow`: the usage section;
  - `ToastViews`: kind colours and override text.
- **Checks:**
  - `swift test`, both shell tests and the bundle all pass;
  - an offscreen render of the footer and of the tinted orb;
  - by hand, through the simulator.
